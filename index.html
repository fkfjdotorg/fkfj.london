What is this

FKFJ is a DIY festival of technology, music, art, and community across London.

By sheer coincidence it takes place on the same dates as SXSW, but is actually affordable and has events you might want to attend.

Anyone can host an FKFJ event! Let us know if you'd like to be listed, have a venue to share, or a thing you would like to put on.

Got questions? hello@fkfj.london
